# IPL Cricket Simulator 🏏⚡

A futuristic single-file IPL cricket simulator built entirely using Python and Pygame.

This project combines fast-paced cricket gameplay, tournament systems, dynamic scoreboards, and a neon-inspired UI into one massive standalone Python file.

Unlike most modular game projects, this simulator is intentionally designed as a **single-file game engine** — making it unique, portable, and surprisingly powerful.

---

# ✨ Features

- 🏏 Full IPL-style cricket simulation
- ⚡ T20, ODI, and Test match modes
- 🧠 AI batting and bowling logic
- 📊 Live scorecards and statistics
- 🎯 Ball-by-ball gameplay simulation
- 🏆 Tournament and league systems
- 🌌 Futuristic neon UI
- 👥 Multiple IPL teams and players
- 🎖️ Player of the Match system
- 📈 Dynamic innings progression
- 🎮 Pygame-based interactive menus
- 🔥 Entire game contained in ONE Python file

---

# 🧠 Why One File?

This project intentionally avoids splitting code into multiple files.

The goal was to create:
- a fully self-contained cricket game,
- easy to share,
- easy to run,
- and unique in structure.

Everything — gameplay engine, UI, tournament logic, scoreboards, AI systems, and rendering — exists inside one large Python script.

# 🏏 Customizing Teams and Players

You can edit teams, player names, batting ratings, bowling ratings, and other values directly using Python IDLE.

## How To Edit Teams

1. Right click the Python file
2. Open with **Python IDLE**
3. Find the team/player section
4. Edit player names or ratings
5. Save the file
6. Run the game again

Example:

```python
Player("Virat Kohli", 95, 12, 88)
```

You can customize:

* Player names
* Batting ratings
* Bowling ratings
* Fielding ratings
* Team lineups
* Team strengths

This allows players to create:

* custom IPL teams,
* fantasy teams,
* stronger/weaker squads,
* or completely new leagues.
